# Eager 页面参考 · r11增量维护

本目录沿用历史业务示例，r11补充[可配置标签、编辑与通知组合](patterns/README.md)，并在有横向溢出的行操作表中默认右固定操作列。数据、字段与页面组合仍是示例，不作为所有项目模板。

本目录运行`python3 preview.py`后访问 http://127.0.0.1:8778/#dashboard 。预览服务停止或电脑重启后需重新启动；发送完整文件夹或ZIP给同事。

本轮入口：经营概览`#dashboard`、采购订单`#orders`、供应商档案`#suppliers`、履约工作台`#fulfillment`、采购申请`#purchase-request`。

- 同排四项指标等宽等高；第一项沿用规范浅灰底强调。颜色强调需核对标题、数值、单位及比较文字在背景上的可读性，深色背景对应浅色文字。
- 数字与单位采用实际字体基线/数字字形测量校正，不以flex盒子齐底冒充字形齐底。字体加载、周期切换与页面显示时重新计算，缺Bebas继续按约定提醒并使用替代。
- 折线点和日期标签共用横坐标，标签居中，首尾预留标签宽度。7/30日切换、hover浮层与分析下钻继续可操作。
- 表格筛选即时生效，无独立查询/重置。规范搜索框保留源蓝色搜索图标及清空入口；关键词短暂防抖，选择器即时更新，状态/采购员名称在未选时显示于选择器内部。选择器逐项清除，金额可直接清空；非法范围保留原结果并提示。
- 示例：订单状态“等待收货”19条，叠加采购员“陈思远”5条，再填金额5000至10000为1条，不需要点击查询。字段/条件变化回第一页并清空勾选。
- 履约抽屉仅保留顶部关闭与底部跟进业务操作；供应商抽屉底部仅编辑资料；申请详情无重复关闭底栏。编辑保存/取消及脏数据确认各有不同含义，继续保留。

本地模拟数据，只在当前页面会话保存；刷新恢复。各业务场景是独立示例数据集，未连接真实接口，也不会实际提交采购。标准组件沿用指定MasterGo副本快照，业务区域保留约束内的UI设计空间。本包无字体文件。

本包中的历史验证范围见`../validation/`；本轮新增范围见`../../references/r11-validation.md`。各轮证据不能互相替代，不引用未随包交付的原工程qa路径。
