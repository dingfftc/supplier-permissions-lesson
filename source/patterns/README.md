# 可复用组合与最小交互参考

`interaction-example.html` 是联系人分类列表、对象详情和通知草稿的最小组合示例，不是所有后台页面模板。用 HTTP 服务打开，资源从页面参考根目录相对加载。所有数据为模拟样本，保存只写当前页面内存，不发送短信、不调用真实业务系统。

## 帮助函数

`list-patterns.js` 暴露 `EagerListPatterns`。

- `tagGroup(items, {maxPerRow, emptyText, tone})`：输出只读标签。容量没有全局默认5；不传容量只按容器自然排列。本例列表传5、详情和材料组传3。按容量分组后，容器确实放不下长文案时可以自然折行，不能靠缩字塞满；超过容器的单条文案保留完整title。标签没有点击事件、手形或“点击修改”等提示。
- `tagFilter(host, {options,value,onChange})`：可交互标签筛选，使用button/aria-pressed。灰默认与蓝色变体的视觉值直接来自 `business-assets/sources/22-126488/fragment.html`、`792-011056/fragment.html`。两者均24px高、padding3px6px、字体14/18、圆角4。灰是#F7F8FA/#E5E6EB/#4E5969，蓝是#F5F9FF/#BEDAFF/#165DFF。蓝色用作hover和选中反馈是此组合的实现选择，并非伪造一个名为hover的源节点。
- `createEditSession(initial, {onCommit,equal,validate})`：plain JSON数据的草稿边界。`get/replace/dirty/cancel/save`分别读取/替换/检查/取消/提交草稿。`save`无变化时不调用onCommit；验证失败和并发提交也不写入；回调完成后才更新提交基线。数组次序不属于业务修改时，调用方传相应equal比较器。该帮助函数不负责决定业务字段、权限或哪个层级应提交。

- `taskToolbar(host,{queries,actions,arrangement,reason})`：把实际控件组和动作组映射为一个可复用工具栏。默认`compact`采用正常流分组，不被普通的`space-between`/`margin-left:auto`覆盖；`separated`允许不同任务/层级分离，但由设计者在`reason`记录任务收益，不要求用户逐项批准。声明理由不等于设计通过，仍实际看宽窄屏。8/16/40间距沿用本组合采用的表格筛选样例，不是所有业务内容的全局间距。

## 本例的具体选择

- 列表标签容量5，材料组和详情容量3。列宽根据样本内容选择，分类列承担可伸展余宽，避免全部列固定宽时挤偏首操作；数字不是团队源参数。样本包含3短、5短、6短、长文案和无分类。
- “未识别”“未接通·无摘要”承担本列主要占位，使用14/24；负责人、地区等辅助信息为12px。本例不主张所有灰字或所有文字至少14px。
- 同一分类修改只有详情的一个入口和弹窗内一个提交点。未修改时保存禁用；取消/脏关闭不写数据。通知草稿有独立提交边界，不能与分类保存合并。
- 通知表单使用顶置标签，正文宽度跟随560px源弹窗的内容区，不写死512px。500字是此示例明确给定的通知容量，不是所有通知/字段的统一限额。原选择器、必填标记、计数、超限校验、模板切换和脏关闭继续有效。
- AI图形来自9154:38141，蓝紫渐变仅示例强调；建议内容按给定动作和对象组织；第二条记录的模拟输入明确给定11月12日前，只有该条显示时效，其他无时效输入不补时限或同步结果。没有建议数据时不造建议卡。
- 数据导出图形为636:033506，仍导出当前结果CSV。字段说明下载图形为636:033563，下载独立的字段说明文本。未接通使用8344:36134。图形与行为分别核验。
- 右固定操作与细横条调用上一层 `table-behavior.js/css`，只声明本表`data-fixed-actions="right"`。不含操作的表格不因此生成操作列。

`PatternExample.getState()` 提供当前内存快照、两种实际写入次数和提示记录，供流程验证；DOM声明只用于找到检查对象，不能代替几何、命中和实际交互证据。
